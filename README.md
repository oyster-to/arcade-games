# Oyster Arcade — community games

Games contributed to **[arcade.oyster.to](https://arcade.oyster.to)**. One folder
per game under [`games/`](games/). Anyone can add one with a pull request.

**Adding a game?** If you're using an AI agent (Claude, etc.), point it at
[`AGENTS.md`](AGENTS.md) — it has the full step-by-step. The same guide works for
humans.

Quick version: copy [`games/example-tap/`](games/example-tap/), edit it, run
`node validate.mjs <id>`, open a PR. A maintainer reviews and merges.
